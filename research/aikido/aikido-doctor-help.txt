##### aikido-doctor request --help
NAME:
   aikido-doctor request - List packages blocked pending approval, and ask your admin to approve them

USAGE:
   aikido-doctor request [command options]

OPTIONS:
   --json                               Print machine-readable NDJSON (one package per line) instead of a table (default: false)
   --package value [ --package value ]  Request this package name (repeatable, or comma-separated)
   --event value [ --event value ]      Request the package of this blocked event id: the full id, or a prefix only one event has
   --yes, -y                            Request every package that is still waiting, without prompting (default: false)
   --help, -h                           show help

##### aikido-doctor certconfig --help
NAME:
   aikido-doctor certconfig - Manage per-tool certificate trust configuration (node, git, java, etc.)

USAGE:
   aikido-doctor certconfig [command options]

COMMANDS:
   list             List certconfig rules, what they configure, and their current state
   disable          Disable a certconfig rule and uninstall its trust configuration (use "all" for every rule)
   disable-repairs  Stop automatic drift repair for a certconfig rule, without uninstalling it (use "all" for every rule)
   enable           Re-enable a certconfig rule and re-install its trust configuration (use "all" for every rule)
   repair           Check a certconfig rule for drift and reinstall it if needed (use "all" for every rule)
   refresh          Reinstall every enabled certconfig rule and rebuild its CA bundles now, whether or not drift was detected
   adopt            Adopt an extra CA from a PEM file into the CA bundles we build (node, npm, pip, git, ruby, curl, nix, bazel), so tools pointed at them keep trusting it
   help, h          Shows a list of commands or help for one command

OPTIONS:
   --help, -h  show help
